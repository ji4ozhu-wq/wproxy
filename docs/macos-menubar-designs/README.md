# macOS 菜单栏图标 + 快捷操作菜单 · 设计候选

四套菜单栏（系统托盘）下拉菜单设计；每套包含菜单栏图标状态 + 展开面板。
截图区域：右上角菜单栏 + 下拉面板；表格里的实现方式是选定后的技术方案。

| 方案 | 风格 | 关键内容 | 实现方式 |
|---|---|---|---|
| A | 原生 NSMenu | 状态头、断开连接、当前节点、分流、下载/上传/时长、设置/关于/退出 | `NSStatusItem` + `NSMenu`（系统默认菜单，最简单、最省事） |
| B | Liquid Glass 卡片 | App 图标+已连接 pill、渐变断开按钮、节点/分流卡片、三列流量、操作列表 | `NSStatusItem` + `NSPopover` 自定义 SwiftUI 面板（与 App 风格统一） |
| C | 紧凑工具面板 | 状态+延迟、连接开关、节点/分流、流量、设置/退出 | `NSPopover` 自定义 SwiftUI 紧凑面板（类 Surge / Stats） |
| D | 极简大按钮 | 大圆形连接按钮、节点/分流、三列流量、图标操作 | `NSPopover` 自定义 SwiftUI 面板（状态优先） |

## 菜单栏图标
- 统一使用模板图标（SF Symbol 风格，随菜单栏明暗自动切换颜色），旁边可叠加绿色状态点表示已连接。
- 点击图标弹出上面的面板；面板内“连接/断开”直接操作隧道，“当前节点/分流/设置”跳转或弹出对应页面。

## 说明
- A 只能呈现系统菜单排版；B/C/D 是自定义弹出面板，可以实现玻璃质感、按钮、指标卡等富内容。
- 也可以混搭：例如「A 的菜单项结构 + B 的玻璃质感」。
