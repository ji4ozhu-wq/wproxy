# macOS 版 · iOS 原生 App 风格设计稿（3 套）

每条风格一套：连接页 + 设置页（`*-set.png` 为拼图，另有单独 `*-home.png` / `*-settings.png`）。
窗口按 1200×760 渲染；侧栏沿用 iPad 风格（连接 / 节点 / 设置）。
当前 App 代码未改动，等选定后再实现 macOS 分支。

## 1 · iOS 18 设置风
`ios18-settings-set.png`
- 系统浅灰底 `#F2F2F7` + 白色分组卡片（圆角 12）
- 每行左侧彩色圆角图标（蓝/绿/橙/紫，类似 iOS 设置）
- 蓝色胶囊「连接」按钮；绿色 iOS 开关；细分割线
- 行高 42–48；标题 28；正文 16；指标 22

## 2 · iOS 活力卡片风
`ios-vibrant-set.png`
- 连接状态为蓝色渐变 Hero 卡片（`#0A84FF → #64D2FF`，圆角 20，白字 + 白色胶囊按钮）
- 本次会话 = 4 张白色圆角指标卡（彩色图标 + 大数字）
- 其余为白色分组卡片；浅灰系统底
- 标题 28；正文 16；指标 22–24

## 3 · iOS 26 Liquid Glass 风
`ios26-glass-set.png`
- 柔和浅色渐变背景 + 半透明玻璃卡片（圆角 20、白色高光描边）
- 彩色图标使用同色系浅底（玻璃风）
- 蓝色渐变胶囊「连接」按钮；iOS 风格开关；卡片阴影很轻
- 标题 28；正文 16；指标 22

## 说明
- 三套都保持扁平单列布局与当前页面信息结构（连接状态 / 当前 / 本次会话 / 连接详情）。
- 选定后只改 macOS 分支，iPhone/iPad 外观与逻辑不变。
