## 4. 背景与调研

### 旧 App 概况

- App Store：https://apps.apple.com/cn/app/无极代理/id1448657437
- 名称：无极代理；Bundle ID：`com.juejin.ios.wuji`；主体：绍兴天穹网络科技有限公司；工具类；免费+内购；版本 3.2.1（2020-04-23 最后更新）；最低 iOS 9.0
- 旧版截图（`screenshots/input/01-old-app-store.jpg`，仅作功能参考）：绿色主题；首页显示出口 IP + 归属地、账号、共享版授权；按钮 暂时断开 / 更换IP / 退出无极；底部流量、剩余天数、续费。
- 用户目标：旧界面太丑、难用 → 全新视觉与交互重做，功能按新版清单重来。

### 引擎可行性（已实测）

- `XTLS/libXray`（MIT）本机构建成功：`python3 build/main.py apple go` → `LibXray.xcframework`（iPhone 真机 arm64、模拟器 x86_64+arm64、macOS、tvOS）。
- 对外 API：`Invoke(requestJSON) -> String`；含 `convertShareLinksToXrayJson`（VMessAEAD/VLESS/SS/SOCKS/Trojan/Hysteria2，不支持 legacy vmess base64，需要自行兼容）。
- NE 限制：扩展内存约 50MB、**模拟器不支持 Packet Tunnel → 只能真机**；需 NetworkExtension（packet-tunnel-provider）entitlement + App Group；VPN 类须组织账号（已满足）。
- 数据面方案：NE packetFlow ↔ tun2socks ↔ 本地 socks ↔ Xray socks inbound；utun fd 获取方式与 tun2socks 选型待专项调研回收后定稿。
- geo 数据：全量 geoip.dat ≈23MB 不可行；`geoip-only-cn-private.dat` ≈236KB；其他国家直连需自建紧凑国家 IP 库并在连接时生成 Xray 路由规则。

### 网络与构建环境

- 用户提供 socks5 代理 `192.168.31.88:9966`（仅开发期访问 GitHub/下载依赖用；不进 App、不进代码）。
- 本机：macOS 26.7.1 + Xcode 27.2、Go 1.26.0（GOTOOLCHAIN=auto 自动拉 1.27.3）、真机 `Wanli的iPhone 16`、开发者团队 C544N77LD9。

## 7. 第二轮架构定稿（2026-11-20 10:00，审计后）

- **分流数据源**：`https://github.com/v2fly/geoip`（实测其 release 由 **DB-IP Lite（CC BY 4.0）** 编译，经 v2fly 以 **CC BY-SA 4.0** 发布；不是 MaxMind。已按真实来源署名，用户确认「就用 v2fly/DB-IP」）。
- **分流判断方式**：运行期由 Xray 按**目的 IP 查 GeoIP 数据库**判断国家，不把 CIDR 展开进配置；routing 里只有 **1 条** direct 规则（`ip: ["ext:<asset>:cn", …]`，含 PRIVATE），通过配置 `env["xray.location.asset"]` 指向连接级资产目录。
- **数据体积/更新**：内置 `geoip.dat.gz`（4.4MB，解压 23.8MB）+ 国家元数据；连接时只抽取选中国家的 entry 生成小型资产（CN 0.23MB / JP 0.63MB / US 3.97MB）。发版内置最新快照；运行期**仅 VPN 连接后**检查，>7 天才下载，失败**固定 1 小时重试**直到成功。
- **UI**：「全局模式」是分流页里的**一个开关**（不是单独 tab/分段）；开启后所有流量走节点、直连项禁用。
- **测速**：连接时当前节点用 Test URL 经隧道测 HTTP 延迟；其他节点 TCP 握手；HTTP 失败回落 TCP。
- **连接中修改**：切换节点 / 改分流 / 改局域网开关 → 自动重连生效。
- **删除当前节点/订阅**：先断开隧道再删除。
- **合规**：主 App + 扩展都声明 NetworkExtension entitlement；PrivacyInfo.xcprivacy（SystemBootTime 35F9.1）进入两个 bundle；移除错误的「无非豁免加密」预声明（改为 App Store Connect 申报）；DNS（DoH 1.1.1.1）与 GeoIP 数据下载写入隐私政策。
