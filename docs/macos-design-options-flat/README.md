# macOS「扁平 + 系统风格」设计候选（2026-11-22 第二轮）

要求：扁平化、系统原生风格；不要玻璃/渐变/发光；字更大；减少空白。
共同规则（三套一致）：SF 字体、系统灰底 + 白色分组面板、0.5px 细分割线、圆角 8、
系统蓝 `#0A6FF5`、行高 44–52、正文 14.5pt、标题 23pt、指标数字 22–26pt；
没有投影、没有渐变、没有玻璃材质。

## A · 单列系统设置风（推荐）
`option-a-single-column.png`
- 单列内容列（约 840pt 宽），分区：连接状态 / 当前 / 本次会话 / 连接详情。
- 最接近 macOS 系统设置面板：状态行 + 原生蓝色「连接」按钮，其余为只读信息行。
- 内容基本填满窗口，空白最少。

## B · 双栏工作台风
`option-b-two-column.png`
- 左栏：连接状态 + 连接按钮 + 本次会话 2×2 指标；右栏：当前节点/分流 + 连接详情。
- 利用横向空间，信息密度高，适合大窗口；左右两栏高度接近。

## C · 工具栏 + 表格风
`option-c-toolbar-table.png`
- 连接状态与「连接」按钮放在窗口工具栏；内容区是三段纯表格（当前 / 本次会话 / 连接详情）。
- 最"工具类 App"（类似 Proxies/Network 面板），视觉最扁平。

- 用于说明同一套 token 应用到设置页的效果（分组行、开关、蓝色链接、细分割线）。
