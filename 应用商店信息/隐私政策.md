# 无极代理 / WProxy 隐私政策

生效日期：2026 年 11 月 20 日
运营者：无极代理 / WProxy 开发者
联系邮箱：ji4ozhu@gmail.com

## 1. 摘要
无极代理（以下简称“本 App”）是一款**连接用户自有服务器**的代理客户端。我们不运营代理服务器，不提供节点，不要求注册账号，也不收集、出售或共享你的个人数据。你的节点、订阅和设置默认只保存在本机。

## 2. 本机保存的数据
为了让你正常使用 App，以下数据会写入本机数据库或 App Group 容器：
- 节点资料：名称、协议、服务器地址、端口、UUID/密码/SOCKS5 凭据、传输与 TLS 配置；
- 订阅资料：订阅 URL、名称、最近更新状态、流量/到期信息；
- 设置：分流模式、DNS 模式、语言、跳过国家/地区、局域网开关、测速地址、当前节点等；
- 运行状态：当前隧道配置、连接状态、本次流量统计；
- GeoIP/geosite 数据文件。

上述数据不会由我们上传到服务器。你可以在 App 的“设置 → 清空数据”中删除；卸载 App 通常会删除本机数据，但 iOS 可能保留 App Group 容器，建议先在 App 内清空。

## 3. 网络请求与第三方
本 App 不会向我们的服务器发送使用数据、分析数据、崩溃报告或广告标识。实际网络请求包括：

- **代理连接**：你连接节点后，流量经 iOS VPN 隧道发送到你配置的服务器。该服务器由你或第三方运营，不经过我们，我们无法查看你的访问内容。
- **订阅更新**：App 直接请求你填写的订阅 URL；订阅提供方会看到你的网络请求和 IP。订阅 URL 可能包含访问令牌，请妥善保管。
- **延迟测试**：App 会向节点发起 TCP 连接，并在已连接时请求你配置的测速 URL（默认是 `https://www.gstatic.com/generate_204`）。结果仅保存在本机。
- **DNS**：
  - 远程 DoH 模式：中国域名通过 `223.5.5.5` / `119.29.29.29` 直连解析；其他域名通过代理使用 `1.1.1.1` / `8.8.8.8` 的 DoH 解析。
  - 本地 DNS 模式：直接使用 `8.8.8.8` / `1.1.1.1` 解析。
  - 上述公共 DNS 解析器会看到对应的查询内容；代理服务器在处理 DoH 时也可能看到目标地址。我们不会收到或记录这些查询。
- **GeoIP 数据更新**：App 从 v2fly/geoip 的公共发布镜像（如 jsDelivr、GitHub）下载公开的 GeoIP/geosite 数据，不包含账号或设备信息。
- **Apple 服务**：付费购买、TestFlight、系统诊断等由 Apple 按其政策处理，我们无法访问你的 Apple ID 支付信息。

第三方可能位于你所在国家/地区之外；使用代理、订阅和公共 DNS 时，请自行评估相关风险。

## 4. 权限
- **VPN / 网络扩展**：用于创建系统 VPN 隧道，把流量转发到你选择的服务器。
- **本地网络**：用于完成 iOS 的本地网络/VPN 相关授权流程，并支持你启用“局域网不代理”；我们不会扫描、收集或上传你的局域网内容。
- **相机**：仅在你主动扫码时使用。
- **相册**：仅在你主动选择二维码图片或保存二维码时使用。
- 通知、定位、通讯录、麦克风：本 App 不请求这些权限。

## 5. 我们不收集的数据
我们不收集账号、姓名、手机号、邮箱（联系客服时除外）、设备标识符、精确位置、通讯录、浏览记录、连接日志或广告标识；App 内没有广告 SDK、分析 SDK 或第三方追踪 SDK。

## 6. 安全
节点凭据和配置保存在本机受 iOS 数据保护的容器中；运行的隧道配置使用文件保护，并在断开后删除。我们未对本地数据库做额外加密，请使用设备锁屏密码并妥善保管设备。任何代理协议的安全性、服务器可信度和隐私表现取决于你选择的服务器，我们不提供保证。

## 7. 保留与删除
本机数据保留到你删除它为止。你可以在 App 内清空数据，或卸载 App。订阅提供方、DNS 解析器和代理服务器按其自身政策保留数据，我们无法代为删除。

## 8. 儿童
本 App 不面向 13 岁以下儿童，也不会有意收集儿童数据。

## 9. 变更
我们可能更新本政策。重大变更会通过版本更新说明或 App 内提示告知；继续使用即表示接受更新后的政策。
